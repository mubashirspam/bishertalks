4. Sandbox environment is not responding

Requests to https://test.cept.gov.in/beextcustomer fail before any HTTP exchange takes place. The TCP connection on port 443 is accepted, and the TLS handshake is then reset by the peer with zero bytes received — no server certificate is presented.

$ curl -X POST "https://test.cept.gov.in/beextcustomer/v1/access/login"
curl: (35) Recv failure: Connection reset by peer

$ openssl s_client -connect test.cept.gov.in:443 -servername test.cept.gov.in
write:errno=54
no peer certificate available
SSL handshake has read 0 bytes and written 1547 bytes

This is not a client-side or credential problem. Observed behaviour:
