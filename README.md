# Life Coach Bisher KC - Portfolio Website

A modern, neon-themed portfolio website built with Next.js 15, featuring smooth animations, dark theme, and responsive design.

## 🚀 Features

- **Modern Neon Design**: Eye-catching cyan, purple, and pink neon color scheme
- **Fully Responsive**: Optimized for all devices and screen sizes
- **Smooth Animations**: Engaging hover effects and transitions
- **Component-Based**: Each section is a separate, reusable component
- **SEO Optimized**: Proper meta tags and structured data
- **Performance Optimized**: Built with Next.js 15 and Turbopack

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5.2
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Build Tool**: Turbopack
- **React**: 19.1.0

## 📁 Project Structure

```
bisher_talks/
├── app/
│   ├── globals.css          # Global styles and animations
│   ├── layout.tsx           # Root layout with metadata
│   └── page.tsx             # Main page component
├── components/
│   ├── Navigation.tsx       # Fixed navigation header
│   ├── Hero.tsx             # Landing section
│   ├── WhatIDo.tsx          # Services section
│   ├── ToolsTechniques.tsx  # Methods and tools
│   ├── About.tsx            # Personal story
│   ├── VisionMission.tsx    # Vision and mission
│   ├── CoreValues.tsx       # Core values
│   ├── Expertise.tsx        # Professional expertise
│   ├── WorkExperience.tsx   # Work platforms
│   └── Footer.tsx           # Footer with links
└── package.json
```

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

4. **Start Production Server**
   ```bash
   npm start
   ```
